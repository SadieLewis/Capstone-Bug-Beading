# Capstone Project: Bug Beading


## Summary:

A website created for the small business Bug Beading, it is a standard
website based on ASP.NET Razor Pages with a supervised learning ai embedded. 
The supervised learner will be able to recognize where user interactions are on the website
and then give the client marketing data to see where they need to advertise or rearrange.


## Implementation:

This project contains a supervised learner embedded into the javascript of the program. As such, it should
be able to identify user interactions with the website and spit out the data it obtains. Additionally, 
with this website project a user can view the home page, inventory, or spotlight.
